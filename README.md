# Page Pulse

Website SEO & Performance Analyzer

## Features

- Analyze Website URL
- HTTP Status
- Response Time
- Page Title
- Meta Description
- H1 Count
- Images Missing Alt
- Word Count

## Tech Stack

Frontend
- HTML
- CSS
- JavaScript
- Vite

Backend
- Node.js
- Express
- Axios
- Cheerio

## Run Project

Frontend

```bash
npm install
npm run dev
```

Backend

```bash
node server/index.js
```
